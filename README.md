📝 ONLINE EXAM SYSTEM

A desktop-based Online Examination System built with Python (Tkinter) for the GUI and SQL for database management. This project allows students to register, log in, and take timed exams on various subjects, while admins can manage students and view results.

🎯 FEATURES

- User Authentication – Separate login for Students and Admin
- Multiple Subjects – Python Programming, Mathematics, General Knowledge, Computer Science
- Timed Assessments – Each exam has a countdown timer
- Instant Results – Get your score, percentage, and grade immediately after submission
- Progress Tracking – Dashboard shows exams taken, passed, failed, and average score
- Admin Panel – View system overview, manage students, and check all exam results
- Result History – Detailed record of student performance with date and time

🖥️ TECH STACK

- Frontend/GUI: Python (Tkinter)
- Backend/Database: SQL (SQLite/MySQL)
- Language: Python
